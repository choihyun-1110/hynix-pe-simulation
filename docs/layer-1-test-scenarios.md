# Layer 1 Test Scenarios

Upkinsey prototype의 Layer 1 입력창에 바로 복사해서 붙여넣을 수 있는 테스트 시나리오 모음입니다.

각 시나리오는 Layer 1 필드 순서에 맞춰 정리했습니다.
Layer 2에서는 목적에 따라 `Concept test`, `Pricing test`, `Objection mining`, `Segment discovery` 중 하나를 선택하면 됩니다.

## 1. 대학 창업팀용 시장 검증 앱

**추천 Layer 2 기준:** Concept test  
**추천 sample size:** 100  
**추천 seed:** 42

```text
제품명
Upkinsey

한 줄 설명
초기 제품 아이디어를 입력하면 한국 synthetic persona 100명이 구매 의향, 가격 저항, 주요 우려, 다음 인터뷰 질문을 빠르게 평가해주는 시장 검증 앱

핵심 기능
제품 brief 입력, synthetic persona 시뮬레이션, persona별 반응 확인, 가격 저항 분석, objection 요약, Markdown 리포트 생성

가격 옵션
무료 체험, 월 29,000원, 팀 플랜 월 99,000원

타깃 고객
대학 창업팀, 초기 스타트업 팀, 창업 수업을 운영하는 교수자와 액셀러레이터

현재 대체 행동/경쟁 대안
직접 지인에게 물어보기, 구글폼 설문, ChatGPT에 개별 질문하기, 실제 인터뷰 전에 감으로 판단하기

확인할 가설
초기 창업팀은 실제 인터뷰를 시작하기 전에 빠르게 가설을 좁히고 질문을 정리할 수 있다면 월 구독료를 지불할 의향이 있을 것이다.
```
