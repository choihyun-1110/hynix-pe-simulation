# Upkinsey 서비스 필요성 근거 자료 — PPT용

> 목적: Upstage API + synthetic persona 기반 pre-research 서비스의 필요성을 설명하기 위한 공신력 있는 주장/수치 모음.
> 사용 톤: “실제 UX/시장조사는 중요하지만, 비용·시간·채용 병목 때문에 초기 아이디어 단계에서 충분히 반복하기 어렵다. 따라서 실제 조사를 대체하는 것이 아니라, 실제 조사 전에 가설을 빠르게 좁히는 pre-research layer가 필요하다.”

---

## 1. 문제: 시장 니즈 검증 실패는 스타트업 실패의 핵심 원인

### PPT 문장
- CB Insights가 101개 스타트업 실패 post-mortem을 분석한 결과, 가장 많이 언급된 실패 원인은 “시장 니즈가 없는 문제를 푸는 것”이었다.
- 해당 요인은 실패 사례의 42%에서 언급되었다.
- 즉, 제품을 만들기 전에 “누가 왜 필요한가?”를 빠르게 검증하는 과정이 중요하다.

### 근거 원문 요지
- “Building a solution looking for a problem, i.e., not targeting a market need”가 #1 reason.
- “Tackling problems that are interesting to solve rather than those that serve a market need was cited … in 42% of cases.”

### 출처
- CB Insights, *The Top 20 Reasons Startups Fail*, 101 startup failure post-mortems 분석 PDF
- https://s3-us-west-2.amazonaws.com/cbi-content/research-reports/The-20-Reasons-Startups-Fail.pdf

## 2. UX/사용자 조사는 비즈니스 성과와 연결된다

### PPT 문장
- McKinsey는 300개 상장사를 5년간 분석해, 강한 디자인 역량을 가진 기업이 업계 benchmark 대비 더 높은 성장을 보인다고 보고했다.
- 상위 McKinsey Design Index 기업은 5년 동안 revenue growth가 32% 높고, total returns to shareholders가 56% 높았다.
- 핵심 실천 중 하나는 “end users와 지속적으로 듣고, 테스트하고, 반복해 개발 리스크를 낮추는 것”이다.

### 근거 원문 요지
- AMA가 요약한 McKinsey 보고서: 300 publicly listed companies, 5 years, 2M+ financial data, 100,000+ design actions.
- Top-quartile MDI scorers: 32% higher revenue growth, 56% higher total returns to shareholders.
- MDI action cluster includes “De-risking development by continually listening, testing and iterating with end users.”

### 출처
- American Marketing Association summary of McKinsey, *The Business Value of Design*
- https://www.ama.org/marketing-news/the-business-value-of-good-design/
- McKinsey report link in article: https://www.mckinsey.com/~/media/McKinsey/Business%20Functions/McKinsey%20Design/Our%20insights/The%20business%20value%20of%20design/The-business-value-of-design-vF.ashx

## 3. 하지만 전통적 사용자 조사는 작게 해도 비용과 운영 부담이 있다

### PPT 문장
- Nielsen Norman Group은 usability test에서 “5명 테스트”만으로도 약 85%의 usability 문제를 찾을 수 있다고 설명한다.
- 하지만 이 작은 규모조차 참가자 모집, 일정 조율, 인센티브, 분석 시간이 필요하다.
- 그래서 초기 아이디어 단계에서는 “많이, 빠르게, 반복적으로” 가설을 걸러내기 어렵다.

### 근거 원문 요지
- “The best results come from testing no more than 5 users and running as many small tests as you can afford.”
- “After the first study with five participants has found 85% of the usability problems…”

### 출처
- Nielsen Norman Group, Jakob Nielsen, *Why You Only Need to Test with 5 Users*
- https://www.nngroup.com/articles/why-you-only-need-to-test-with-5-users/

## 4. 참가자 인센티브만 해도 비용이 빠르게 커진다

### PPT 문장
- Respondent의 2025 incentive guide에 따르면, 미국 기준 broad audience remote participant도 1명당 약 $90, niche audience는 $120 수준을 제안한다.
- 비즈니스 전문가/기술직/의료직처럼 특정 타깃일수록 remote interview 인센티브는 $100~$1,000+까지 올라간다.
- 즉, 10~20명만 인터뷰해도 인센티브만 수십만~수백만 원 규모가 될 수 있다. 여기에 모집 플랫폼 수수료와 리서처 인건비가 더해진다.

### 근거 수치
- General population, broad audience remote: $90 / in-person $140
- General population, niche audience remote: $120 / in-person $200
- Business professionals remote: junior $100, manager $200, director $300, VP $400, C-level $600
- Technology professionals remote: security admin/software engineer $100, UX designer/web developer/systems admin $125, data analyst/IT consultant/software developer $150, cyber security analyst $175
- Medical professionals remote: non-doctoral $250, doctoral $500, specialized $1,000

### 출처
- Respondent Help Center, *Determining the right incentive for Research Participants* (Apr 21, 2025)
- https://help.respondent.io/en/articles/5471087-determining-the-right-incentive-for-research-participants

## 5. 모집 플랫폼 비용도 별도로 붙는다

### PPT 문장
- User Interviews의 공개 가격표 기준, 외부 패널 recruiting은 Pay-as-you-go 기준 session당 $49부터 시작한다.
- B2B advanced targeting은 추가 비용이 붙는다.
- 따라서 실제 조사의 총비용은 `참가자 인센티브 + 모집 플랫폼 비용 + 리서처/분석 인건비 + 일정 지연 비용`으로 구성된다.

### 근거 수치
- User Interviews Recruit Pay As You Go: $49/session 공개 표기
- Advanced B2B targeting: +$45/session 공개 표기
- annual plan에서는 session당 가격이 낮아지지만, 반복 조사를 전제로 한 구독/계약 필요

### 출처
- User Interviews Pricing
- https://www.userinterviews.com/pricing

## 6. 정성조사/포커스그룹은 프로젝트 단위로 더 비싸진다

### PPT 문장
- Drive Research는 표준 focus group project 비용을 일반적으로 $10,000~$30,000 범위로 설명한다.
- 비용 요인은 참가자 수, 그룹 수, 세션 길이, 인센티브, 장소/온라인 여부 등이다.
- 즉, 제품 아이디어가 여러 개인 초기 단계에서 모든 아이디어에 대해 풀 리서치를 수행하기는 부담스럽다.

### 출처
- Drive Research, *How Much Does a Focus Group Cost?* (Apr 28, 2023)
- https://www.driveresearch.com/market-research-company-blog/how-much-does-a-focus-group-cost-focus-groups-syracuse-ny/

## 7. 리서치 수요는 증가하지만 조직의 리서치 리소스는 부족하다

### PPT 문장
- User Interviews 2024 State of User Research는 759명의 researcher/UX professional을 조사했다.
- 2024년 조사에서 참가자 모집 시간 문제를 겪는 비율이 61%로, 2023년 45%보다 증가했다.
- 모집 비용 문제도 32%로, 2023년 25%보다 증가했다.
- 동시에 22%는 지난 12개월 동안 회사가 dedicated researcher를 layoff했다고 응답했다.
- 즉, “조사는 더 많이 필요하지만, 조사할 사람과 예산은 줄어드는” 구조적 압박이 있다.

### 출처
- User Interviews, *The State of User Research Report 2024*
- https://www.userinterviews.com/state-of-user-research-2024-report

## 8. 그래서 이 서비스의 포지셔닝

### 핵심 논리
1. 제품 실패의 큰 원인은 시장 니즈/문제 검증 실패다. (CB Insights 42%)
2. 사용자 중심 디자인과 반복 검증은 성과와 연결된다. (McKinsey/AMA 32%, 56%)
3. 하지만 실제 UX/시장조사는 비용·시간·모집 병목이 크다. (NN/g, Respondent, User Interviews, Drive Research)
4. 따라서 실제 조사를 대체하지 않고, 실제 조사 전에 가설·타깃·질문을 좁히는 synthetic pre-research가 필요하다.

### PPT용 한 문장
> Upkinsey는 “실제 사용자 조사를 대체하는 AI”가 아니라, 비싼 실제 조사를 하기 전에 어떤 가설을 먼저 검증해야 하는지 빠르게 좁혀주는 synthetic pre-research layer다.

### 추천 슬라이드 구조
1. 왜 실패하는가: 시장 니즈 검증 실패 42%
2. 왜 조사해야 하는가: 디자인/사용자 검증이 성장과 연결
3. 왜 기존 방식만으로 어렵나: 5명 테스트도 운영·비용 부담
4. 비용 증거: 인센티브 $90~$600+, 포커스그룹 $10k~$30k
5. 조직 병목: 모집 시간/비용 부담 증가, researcher layoff
6. 해결 방향: AI synthetic persona로 “실제 조사 전” 가설 필터링
7. 안전한 주장: 대체가 아니라 pre-research / decision support / question generator
