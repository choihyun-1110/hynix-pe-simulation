왜 필요한가요

복잡한 제품 이슈를 마주하면, 부서별 관점을 빠르게 정리해야 합니다.

PE는 소자, 설계, 공정, 품질, 고객 application 조건을 연결해 weak point를 좁히는 역할입니다. Resonance PE는 깊은 검증 전에 놓칠 수 있는 질문을 먼저 정리합니다.

제품 이슈를 처음 마주했을 때
  • Fail pattern을 한 관점에서만 해석한다
  • 어떤 데이터를 먼저 봐야 할지 정리가 늦어진다
  • 관련 부서에 물어볼 질문이 흩어진다
  • 고객 workload와 내부 test 조건의 차이를 뒤늦게 본다
Resonance PE를 쓰면
  • Fail pattern을 stakeholder별 관점으로 분해한다
  • Device, Design, Process, Test, Customer 관점의 원인 후보를 모은다
  • 추가 확인 데이터와 test action item을 우선순위화한다
  • 부서별 커뮤니케이션 질문과 고객 대응 메시지를 정리한다
